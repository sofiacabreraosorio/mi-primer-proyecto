            <h2>Consejos de seguridad digital</h2>
            
            <article>
                <h3>Protege tus contraseñas</h3>
                <p>Una contraseña segura debe ser difícil de adivinar y diferente para cada servicio:</p>
                <ul>
                    <li>Utiliza letras mayúsculas y minúsculas.</li>
                    <li>Agrega números y símbolos.</li>
                    <li>No compartas tu contraseña.</li>
                </ul>
            </article>

            <article>
                <h3>Reconoce mensajes sospechosos</h3>
                <p>Desconfía de los mensajes que solicitan información personal o que incluyan enlaces desconocidos:</p>
                <ol>
                    <li>Revisa quién envía el mensaje.</li>
                    <li>No abras enlaces desconocidos.</li>
                    <li>Consulta a una persona de confianza.</li>
                </ol>
            </article>
        </section>
